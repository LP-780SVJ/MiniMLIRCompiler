## 2. 验证分级与实际状态

| 级别 | 通过所需证据 | Day 16 状态 |
| --- | --- | --- |
| G0 静态调查 | 仓库和依赖 SHA、补丁清单、目标 Features、主机与工具版本、平台条件。准备实际构建时再验证补丁应用状态及所选环境。 | 已取得固定源码、gitlinks、声明与本机探测。Day 17 需确认运行环境和实际应用状态。 |
| G1 基础仿真器 | 所选版本的官方最小构建、测试命令及实际输出。 | 未执行。 |
| G2 官方 MatMul | 官方模型编译、VMFB 加载、MPACT 执行成功，MatMul 分派到 Coral 并得到 `32×128` 全 128。 | 未执行。 |
| G3 自研导出 | Mini 导出的标准 Linalg 经同一工具链编译，并在已确认的 Coral 分派上验证结果。 | 待 MatMul→Linalg 导出与 G2。 |

证据顺序为目标 Features → 实际指令 → decoder 与指令语义 → ABI 加载和分派 → 数值输出。G2 只为该模型在具体构建组合上的执行提供证据。若反汇编没有某个扩展的指令，G2 不覆盖该扩展。每次运行记录主机、各仓库 SHA、补丁状态、完整参数、退出码、实际数值和日志位置。
